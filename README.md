# Praise Catalogue

Static song catalogue for the [Praise Flutter application](https://github.com/nani-samireddy/praise).

The application repository publishes validated snapshots here automatically.
The public manifest is available at:

```text
https://nani-samireddy.github.io/praise-catalog/catalog/manifest.json
```

This repository contains generated deployment data. Make catalogue source
changes in the application repository.
